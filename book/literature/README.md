# Literature And PDFs

Put PDFs here when you want agents to help with literature review.

Suggested pattern:

- `some-citekey.pdf`: the PDF
- `some-citekey.md`: a short note with the source's relevance, key claims, and status
- `inventory.md`: generated PDF inventory

Agents should not load every PDF into context. They should inventory sources first, identify the likely relevant ones, and summarize only the parts needed for the task.

Do not store credentials here.
