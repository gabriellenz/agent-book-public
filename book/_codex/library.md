# Library And Citations

- `citations/author.bib` contains author-maintained example sources.
- `citations/agent.bib` contains agent-added example sources.
- `literature/` is where users can put PDFs and short source notes.
- Bookdown includes both files.
- Before adding or changing citation metadata, check authors, title, venue, year, DOI, and publication details against Crossref or a primary source record.
- Preserve citation syntax unless editing the sentence substantively.
- Use narrative citation `@key` or parenthetical citation `[@key]`.
