# Bookdown Glossary

- `index.Rmd`: first Bookdown file and whole-book YAML.
- `_bookdown.yml`: chapter order and output filename.
- `_output.yml`: output formats.
- `_common.R`: shared knitr setup.
- Chunk label: the name after `{r ...}`.
- Text reference: `(ref:name)` defines reusable caption text.
- Externalized chunk: a chapter chunk whose code body lives in a separate `.R` file via `file="..."`.
