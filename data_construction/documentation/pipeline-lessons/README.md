# Pipeline lessons

Use this folder for durable lessons learned while debugging or extending a
data pipeline. A lesson belongs here when it is too specific for
`data_construction/_codex/project-rules.md` but too important to leave in
chat or scratch.

Add or update a lesson when work reveals:

- a recurring failure mode;
- a non-obvious data contract;
- a validation check that caught or would have caught an error;
- a sample-size, unit-count, merge, or missing-data trap;
- a raw-versus-clean boundary that later work must preserve; or
- a builder rule that should guide future edits.

Keep notes short and operational. State the symptom or risk, the reliable
check or fix, and the builder or documentation file that owns the behavior.
